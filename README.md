Smart Study Planner 📚

Smart Study Planner is a JavaScript-based application that helps students organize their study schedules, manage subjects, set study goals, and track their progress.

Features
Add subjects and study topics
Set study duration and priorities
Automatically generate a simple study schedule
Track completed study tasks
Calculate study progress
Simple and user-friendly interface
Technologies Used
HTML
CSS
JavaScript
Node.js for testing

└── README.md

How to Run
Download or clone the repository.
Open index.html in a web browser.
Add your subjects, topics, priorities, and study duration.
Click Add Study Task to create your study plan.
Mark tasks as completed to track your progress.
Running the Testbench

Make sure Node.js is installed.

Run:

node test.js


The testbench checks task creation, priority sorting, progress calculation, and schedule generation.
